# Design documents

Design drafts for Trade Wars, kept as self-contained HTML so they can hold
diagrams and tables. Open one in a browser.

A document here is a **proposal under review** until it says otherwise. Each
one states its status in the header: `Draft`, `Accepted` or `Superseded`, and
whether the work is implemented.
